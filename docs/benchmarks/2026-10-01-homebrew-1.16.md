# Homebrew Omnivox 1.16.0 update

This functional acceptance report records the Homebrew follow-up to
[Omnivox 1.16.0 publication](2026-09-30-1.16-publication.md). The tap still
selected 1.13.0 until [pull request 4](https://github.com/bartbunting/homebrew-omnivox/pull/4)
was merged at 2026-09-30 20:31:55 UTC (2026-10-01 in Sydney).
The merged tap commit is `24f20789e5c27d989fc47434d6a8cfdbd24e659f`.

## Verification

The updater downloaded both public 1.16.0 Mac archives and verified their
SHA-256 hashes against the release manifest before changing the formula.
All seven updater tests passed locally.

Both native jobs passed on PR commit
`92bf533a457ef7784d75a51ae42a48b7b933a263` before merge:

- [Apple Silicon](https://github.com/bartbunting/homebrew-omnivox/actions/runs/36772741531/job/110082956762).
- [Intel](https://github.com/bartbunting/homebrew-omnivox/actions/runs/36772741531/job/110082957100).

Each job checked the updater, downloaded archives, formula style, install and
audit, version and voice discovery, eSpeak and Apple speech WAV synthesis,
reinstallation, a temporary packaging-revision upgrade and uninstallation.
The merged formula and test workflow match the tested PR versions.

In a clean checkout of merged tap `main`,
`python3 tools/update_formula.py 1.16.0 --check` downloaded both archives again
and confirmed the formula URLs and hashes. The expected digests were:

| Archive | SHA-256 |
| --- | --- |
| `omnivox-1.16.0-macos-arm64.tar.gz` | `b622ac6d2d33f7ab061831aa05ac16786544632626026e003bc112ab5d99b138` |
| `omnivox-1.16.0-macos-x64.tar.gz` | `68c29d915c19513d58b5095c2e46be9e826f2eb27e4e5ca10ff0aae1d1208adc` |

The [evidence manifest](data/2026-10-01-homebrew-1.16/SHA256SUMS) covers the
merged PR metadata, native job records and logs, and merged-formula check.
These checks do not establish audible Emacs acceptance or a real Homebrew
upgrade from 1.13.0 to 1.16.0; the CI upgrade uses a packaging revision of the
same 1.16.0 payload.
