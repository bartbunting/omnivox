# Omnivox 1.13.0 publication checks

The [1.13.0 release](https://github.com/bartbunting/omnivox/releases/tag/v1.13.0)
was published on 2026-09-28 at 04:44:57 UTC with 28 assets. Its unchanged tag
identifies commit `54aee84575d8a0072e5995b3705959f581e777c8`.
The [release workflow's third attempt](https://github.com/bartbunting/omnivox/actions/runs/36366520107/attempts/3)
finished successfully. These are functional release checks, not performance
measurements or listening tests.

## Results and retries

The release gates passed for the five generic native targets, all documented
companion targets, corresponding-source packages, Debian installation on Ubuntu
24.04 and 26.04, downloaded-archive verification and final asset membership.
The [deployment guide](../../.github/DEPLOYMENT.md#what-ci-validates) defines the
individual checks and platform limits. Rust jobs use the pinned 1.97.1 toolchain
and locked dependencies.

Two failures were investigated before retrying failed jobs:

1. The initial Windows ARM64 unit run failed its startup watchdog assertion.
   A native Windows reproduction identified an early timeout in the test's
   mock connection. The [separate investigation](2026-09-28-startup-watchdog-test.md)
   retains the reproduction, correction and passing local checks. The correction
   is test-only, committed after the release tag, and is absent from the 1.13.0
   source archive. The unchanged tagged test passed on retry.
2. The second attempt reached draft-archive verification, where the 32-bit
   Eloquence helper exceeded the existing ten-second process timeout on Windows
   ARM64 during a missing-runtime check. The helper source and startup harness
   are unchanged from 1.12.1; the same check had passed in the native build job.
   The exact Eloquence and DECtalk helper bytes downloaded from the draft's
   Windows ARM64 archive then passed one local check on Windows x64 through WSL
   interop, from a Windows-local directory. The failed ARM64 verification passed
   on the third workflow attempt. Its original timeout cause remains unknown;
   this result does not establish that the runner caused it.

Neither retry changed the tagged source, the helper binaries or the acceptance
timeouts. Publication remained gated on successful release verification.
