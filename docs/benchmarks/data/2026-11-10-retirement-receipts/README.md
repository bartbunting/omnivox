# Native retirement receipt evidence, 2026-11-10

See [the report](../../2026-11-10-retirement-receipts.md) and the
[exact contract](../../../reference/engine-startup-snapshot.md#reconcile-an-existing-retirement-receipt).
`provenance.json` identifies both source bases and payloads. Compressed source
patches retain the implementation and paired fixture; generated byte-code is not
part of the patches. Windows provenance records the build-time checkout state;
final fixture assertions and documentation were completed afterward.

Run `emacs.py EXE FRESH_DIRECTORY --lose-retirement-reply` against a private
configuration/voice root with the paired client. `--bytecode` requires its current
build/preflight. `--engine piper` selects the retained real helper/model. For a
native Windows executable under WSL, use a fresh directory on the Windows drive
and pass `--skip-crash`; only Linux injects a worker crash through retained pidfds.
`--damage-receipt` additionally corrupts the newly written receipt in that private
test root, preserves its actual original bytes separately and verifies that
replacement stays blocked while the peer speaks. Never use a live profile,
installed runtime, existing output directory or unrelated process as a fixture.
Absolute companion and checkout paths need adaptation elsewhere.

The final fixture submits and completes notification speech inside foreground
recovery and asserts that its owner and acknowledged voice registration stay the
same. Earlier fixture runs did not include this additional assertion; their raw
observations remain separate. All tests use null output and actual engine IDs.
Source-event times are not acoustic timing or tail-latency estimates.

`observations.tar.gz` contains the files listed in `archive-files.txt`, including
raw logs, synthetic configuration, original small retirement receipts from damage
cases, functional reload output and initial failed prerequisite/test invocations.
Complete native startup/owner journals may contain captured environments and stay
in their original private fixture directories; they are not redistributed.
No replacement journal is presented as native ownership evidence.

`linux-payload.sha256`, `windows-SHA256SUMS` and `windows-PROVENANCE` identify the
staged runtimes. The source patches use the commits in `provenance.json`.
`SHA256SUMS` covers this pack; run `sha256sum -c SHA256SUMS` here. The complete raw
archive was read back and verified against its member manifest. All preceding
reports, raw packs and frozen payloads remain unchanged.
