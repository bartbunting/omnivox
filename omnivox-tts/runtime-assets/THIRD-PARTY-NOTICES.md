# eSpeak NG runtime notices

Omnivox release builds contain a statically linked eSpeak NG backend and an
adjacent `espeak-ng-data` directory generated by the same dependency build.
The Omnivox-authored source is declared under the MIT license in the Cargo
workspace; eSpeak NG and the third-party components listed below retain their
own licenses.

The locked dependency is `espeak-rs-sys` 0.1.9. Its bundled eSpeak NG source
states that eSpeak NG is licensed under GPL-3.0-or-later. The complete GNU GPL
text is included as `eSpeak-NG-GPL-3.0.txt`. The locked version, registry
source, and crate checksum are recorded in `omnivox-Cargo.lock` in this
directory.

The staging tool always copies the following files from the exact dependency
build used to stage the runtime data:

- `eSpeak-NG-GPL-3.0.txt`: GNU GPL version 3 text shipped with eSpeak NG's
  `ucd-tools` source;
- `Unicode-Data-License.txt`: the Unicode data-file and software license
  shipped with `ucd-tools`;
- `NetBSD-getopt.c`: the NetBSD-licensed compatibility source and its complete
  notice.

When eSpeak NG builds its fetched Sonic implementation, the tool also copies
`Sonic-Apache-2.0.txt`, the Apache License 2.0 shipped with Sonic at commit
`fbf75c3d6d846bad3bb3d456cbc5d07d9fd8c104`.

Upstream source locations:

- eSpeak NG: <https://github.com/espeak-ng/espeak-ng>
- Rust build/bindings package: <https://crates.io/crates/espeak-rs-sys/0.1.9>
- Sonic: <https://github.com/waywardgeek/sonic/tree/fbf75c3d6d846bad3bb3d456cbc5d07d9fd8c104>

GitHub releases also provide the corresponding Omnivox source tree for each
tag. Preserve this directory with the executable and runtime data when
redistributing a binary package.
